# 微前端示例项目

## 项目简介
这是一个基于 Vue3 + TypeScript + Wujie 的微前端示例项目。项目实现了一个类似操作系统的窗口管理系统，可以同时运行多个独立的微应用。

## 技术栈
- Vue 3
- TypeScript
- Element Plus
- Wujie 微前端框架

## 功能特性

### 1. 应用管理
- **多实例支持**：
  - 同一应用可以开启多个实例
  - 实例自动编号（如：应用.1、应用.2）
  - 实例间状态完全独立
- **应用标识**：
  - 统一的应用图标
  - 清晰的实例编号
  - 一致的命名规则

### 2. 窗口管理
- **窗口操作**：
  - 拖拽移动（通过标题栏）
  - 八个方向调整大小
  - 最大化/最小化/关闭
  - 点击窗口自动提升到最前
- **窗口排列**：
  - 级联排列：窗口按层叠方式排列，自动计算偏移
  - 平铺排列：自动计算最佳布局
    - 1-2个窗口：水平排列
    - 3-4个窗口：2x2 网格
    - 5-6个窗口：2x3 网格
    - 更多窗口：自动计算最佳网格

### 3. 界面交互
- **侧边栏**：
  - 可折叠的应用列表
  - 运行中应用状态显示
  - 应用快速切换
  - 实例快速关闭
- **最小化栏**：
  - 底部显示最小化的应用
  - 点击快速恢复窗口
  - 显示应用图标和编号

### 4. 视觉设计
- **现代化界面**：
  - 清晰的视觉层次
  - 精美的图标设计
  - 合理的空间布局
- **交互反馈**：
  - 窗口拖拽时的平滑动画
  - 最大化/最小化过渡效果
  - 鼠标悬停反馈
  - 状态切换动画

### 5. 微前端特性
- **应用隔离**：
  - 独立的运行环境
  - 样式隔离
  - 生命周期管理
- **数据传递**：
  - 主应用向子应用传递实例信息
  - 统一的通信机制

## 项目设置
```bash
# 安装依赖
npm install

# 开发环境运行
npm run serve

# 生产环境构建
npm run build

# 代码检查
npm run lint
```
